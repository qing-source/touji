## 🧠 交易系统 v2.0 核心

- **双时间框架状态机**：周线闸门（向下=全部仓位×0.5）+ 日线状态（7 态）
- **六模式**：P1 平台突破 / P2 关键点回踩 / P3 反身性加速 / P4 泡沫拐点 / P5 恐慌错杀(辅助) / P6 龙头跟随
- **风控**：单笔 ≤2% 风险（ATR 波动率预算）｜同板块 ≤2 只、合计 ≤4%｜回撤 10% 减半、15% 空仓｜不加杠杆
- **验证**：收盘信号 → 次日开盘成交、含成本、SHA-256、双引擎交叉验证、成本敏感性检验

## 🔧 本地运行与数据管线

```bash
# 静态服务（无缓存，便于调试）
node server.js            # http://127.0.0.1:8686

# 数据刷新（重新下载 → 重建 data.js）
node fetch_all.js         # 3 指数
node fetch_sectors.js     # 板块成分股 + ETF
node fetch_futures.js     # 期货主力
node build_data.js        # 生成 data.js（含 SHA-256）

# 分析与验证
node test_engine.js       # 回测引擎无头验证
node stock_backtest.js    # 个股回测
node analysis_today.js    # 今日盘面综合分析
node audit.js             # 站点体检
```
