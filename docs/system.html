一、现行系统体检：8 个结构性缺陷

01单一日线框架，趋势定义脆弱状态层

现行系统只用日线 20 日均线判断趋势。周线级别已进入下跌趋势时，日线反弹会频繁触发"站上20日线"的假信号（2018 恒生熊市回测中趋势策略仍 -3.7% 即是证据）。

✅ 修复：引入双时间框架过滤——周线 20 周均线方向作为"大环境闸门"：周线向下时，日线信号一律降档执行（仓位×0.5）；周线向上才允许满档。这正对应利弗莫尔"时间要素"（大势未到时，再好的关键点也不出手）。
02市场状态靠人工勾选，主观不可复现状态层

"利好不涨""龙头滞涨"等选项依赖人工判断，不同人勾出不同结论，且无法回测。

✅ 修复：为每个状态定义可计算代理（见第二节量化代理表）——例如"衰竭"用"20日涨幅进入近2年分位 90% 以上 + 5日量能萎缩"近似；让状态机可被历史数据驱动、可回测。
03P3/P6 模式不可回测，决策易拍脑袋策略层

P3（反身性加速）与 P6（龙头跟随）依赖"叙事""板块共振"等软概念，未量化，回测页只能回避——而这两者恰是 A股短线的主要盈利来源。

✅ 修复：给出量化代理——P6 用"板块内当日涨停/涨幅>5% 家数 ≥2"定义共振日，"龙头"用"板块内当日成交额排名第1且涨幅居前"定义；P3 用"20日涨幅 > 15% 且当日涨幅 > 5% 且量能 > 5日均量"定义加速初段。代理不完美，但可测、可统计、可迭代。
04模式选择缺少唯一映射表策略层

大师分诊输出"推荐模式集合"，但"什么状态该用哪个模式、多大仓位"散落在不同卡片里，执行时容易自行发挥。

✅ 修复：建立状态→模式→仓位唯一映射表（见第三节 v2.0 规范），每个状态只有一组允许的模式与仓位档位，杜绝自由裁量。
05固定 2% 单笔风险未考虑相关性风控层

同时持 5 只同板块股票，每只 2% 风险 = 板块实际风险 10%。回撤中相关性趋近 1，等价于把鸡蛋放一个篮子。

✅ 修复：增加板块敞口上限——同一板块最多持有 2 只、板块合计风险敞口 ≤ 4%（即两笔 2%）；全账户同向敞口 ≤ 75% 不变。这符合塔勒布"不把尾部风险叠加"的反脆弱原则。
06止损按收盘价判断，跳空/跌停无法执行风控层

回测假设"次日开盘卖出"，但 A股跌停时根本无法成交；个股闪崩可直接跳过止损位。固定 -5% 止损对高波动标的也不适配。

✅ 修复：引入波动率预算（ATR 缩放）——止损距离 = k × ATR(14)，仓位 = (账户×2%) ÷ 止损距离；波动越大的票仓位越小、止损越宽但风险恒定。跌停预案：触发跌停无法卖出时，次日集合竞价无条件挂单出清（利弗莫尔：止损没有借口）。
07交易日志缺"市场状态"字段执行层

现有日志记录模式/假设/盈亏，但不知道每笔交易发生在哪种市场状态——无法回答"趋势末段做 P6 的期望值是不是负的"。

✅ 修复：日志增加市场状态字段（健康趋势/末段/衰竭/恐慌/弱势/不明），月底按"状态×模式"交叉统计期望值，负期望组合直接淘汰——这是索罗斯"用市场检验假设"的落地。
08回测无稳健性检验，存在过拟合风险验证层

单点参数（成本1‰、固定止损5%）的结果可能依赖参数选择；参数抖动就变差的策略不可信。

✅ 修复：回测页新增成本敏感性检验表（0/1/2/3/5‰ 下总收益、回撤、笔数），若成本翻倍收益坍塌 = 策略无容错空间，应弃用；并补充参数邻域说明（±20% 内结果方向不变才视为稳健）。

四、波动率预算：ATR 仓位计算器（v2.0 风控核心）

仓位 = (账户资金 × 单笔风险率) ÷ (ATR × 止损倍数)。波动越大仓位越小，风险恒定为账户 2%。

五、亏损强制复盘模板（debrief，亏损后 30 分钟内完成）

  1. 这笔亏损来自哪一层？ 状态误判 / 模式错配 / 执行变形 / 运气（黑天鹅）——四选一，不许选"说不清"；
  2. 是否违反任何一条系统规则？ 违反 = 记录为"纪律失败"（无论盈亏，这是唯一真正的失败）；
  3. 量化代理是否提前给了信号？ 回看当时的代理数值，确认是"信号错了"还是"我没执行"；
  4. 这笔交易属于哪个状态×模式组合？ 记入日志，供月底交叉统计；
  5. 下一步动作？ 连亏 2 笔 → 当日停止；连亏 3 笔 → 休市 2 天并复盘全部 3 笔；月回撤 10% → 仓位减半。
这直接落实索罗斯的"谬误性"：亏损不是失败，是假设被证伪的数据点；只有不认错才是失败（利弗莫尔棉花案）。
