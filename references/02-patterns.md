# 02 策略层：短线模式库（Playbook）

> 每个模式包含：名称 / 假设 / 入场 / 止损 / 目标与退出 / 失效条件 / 来源大师

## Pattern 1：最小阻力线顺势（利弗莫尔基础式）
- **假设**：价格沿最小阻力方向延续。
- **入场**：股价创 20 日新高且放量突破整理平台（≥10 个交易日的窄幅区间），次日不回破突破日开盘价则进场。
- **止损**：跌回平台内部（突破失效）或 -5%，取先到者。
- **退出**：趋势加速后出现放巨量滞涨/长上影，或跌破 10 日均线减半、跌破 20 日均线清仓。
- **失效**：突破后 3 日内缩量跌回平台 = 假突破，无条件离场。
- **仓位**：试仓 25%，浮盈后逢回调加仓，总仓位 ≤ 75%。

## Pattern 2：关键点回踩确认（Livermore Pivotal Point）
- **假设**：突破后的首次回踩不破关键点 = 趋势确认。
- **入场**：突破关键点后回踩至突破位 ±2% 且缩量企稳（止跌阳线）时进场——比追突破盈亏比更好。
- **止损**：收盘有效跌破关键点 3%。
- **退出**：同 Pattern 1。
- **失效**：回踩放量击穿关键点。

## Pattern 3：反身性加速段（索罗斯式动量）
- **假设**：正反馈环（价升→叙事强化→资金流入→价升）尚未衰竭。
- **识别信号**：连续放量上涨 + 板块叙事升温 + 融资/成交占比快速抬升 + 老多头开始"越涨越便宜"式唱多。
- **入场**：加速初段（第一根放量长阳后）跟进，绝不参与末段。
- **退出（核心）**：监测衰竭信号——成交量创新高但价格滞涨、龙头股开始补跌、利好出尽不涨。任一出现即离场，不等止损。
- **失效**：政策/监管信号逆转反身性逻辑（如加息、印花税上调、龙头被立案）。

## Pattern 4：泡沫反身性拐点做空/清仓（索罗斯 1992 式）
- **假设**：失衡不可持续，正反馈逆转为负反馈。
- **前提条件（全部满足才行动）**：① 价格严重脱离基本面锚（估值历史极值）；② 维持趋势的工具已耗尽（利率/资金/政策弹药）；③ 出现第一个负反馈事件且市场"利好不涨"。
- **A股短线应用**：主要不做空，而用于**系统性清仓信号**——满足三条件时无条件降仓至 ≤20%。
- **失效**：负反馈事件后市场创新高 = 判断错误，承认并恢复常态仓位规则。

## Pattern 5：恐慌错杀均值回归（辅助，小仓位）
- **假设**：无基本面利好的指数级/板块级恐慌急跌，短期超卖。
- **入场**：大盘恐慌性长阴（跌幅 >3%）次日缩量止跌时，买超跌的强趋势股。
- **止损**：-4% 或跌破恐慌日低点。
- **退出**：反弹至 5 日均线或 +8% 即了结，**不恋战**（这是短线，不是抄底）。
- **来源**：利弗莫尔"市场不会永远跌"；威廉姆斯式超卖反弹。

## Pattern 6：龙头效应跟随（利弗莫尔板块论）
- **假设**："板块运动是交易的基本单位"——涨时龙头先涨且涨最多。
- **入场**：板块出现 2 只以上涨停/大阳的共振日，选最强龙头（最先涨停、量能最大、逻辑最硬），次日不强于板块则换。
- **止损**：跌破共振日启动点。
- **退出**：龙头让位（板块内出现新龙头而旧龙头滞涨）或板块整体退潮。

## 模式选择决策树
```
市场处于趋势中吗？（指数在20日线上方 + 有持续热点板块）
├─ 是 → 热点板块有龙头吗？
│   ├─ 有 → Pattern 6 / 1 / 2 顺势做多
│   └─ 无 → Pattern 3（是否加速段？初段可做，末段不做）
└─ 否（指数弱/暴跌后）
    ├─ 恐慌急跌次日 → Pattern 5（小仓）
    └─ 出现 Pattern 4 三条件 → 空仓/极低仓等待
```
