# 03 执行层：每日交易 SOP 与清单

## 一、盘前（开盘前 30 分钟）
1. 复核持仓：每笔持仓的假设是否仍成立？止损位在哪？写下来。
2. 扫描隔夜信息：外盘、政策、行业新闻——是否证伪任何持仓假设或激活新 Pattern？
3. 确定今日"关键点清单"：关注的突破位/回踩位，写在纸上（**不到关键点不出手**）。
4. 自检情绪（曼宁清单）：失眠/愤怒/报复心/过度兴奋 → 今日禁止开新仓。

## 二、盘中
1. 只在**预设价位**执行，禁止盘中临时起意的新模式。
2. 开仓即设止损（条件单或写定价格），无止损不下单。
3. 每笔交易记录（交易日志模板）：
   - 日期/标的/模式编号 | 假设一句话 | 入场价 | 止损价 | 目标价 | 仓位%
   - 离场后补：出场价 | 盈亏% | 是否遵守规则（是/否）| 教训一句话
4. 连续 2 笔止损 → 当日停止交易（防利弗莫尔式"报复性交易"）。

## 三、盘后
1. 更新交易日志，统计本月：胜率、盈亏比、规则遵守率。
2. 复盘重点不是盈亏，而是**"是否违反了本 skill 的规则"**——违反规则但赚钱记为"失败"，遵守规则但亏钱记为"成功"（马克·道格拉斯原则）。
3. 评估当前市场状态，更新明日的模式选择（决策树）。

## 四、每周/每月
- 每周：统计各 Pattern 的期望值，淘汰连续 10 笔期望为负的模式。
- 每月：检视总资金曲线；回撤触及 10% → 仓位减半；触及 15% → 空仓一周复盘（见 04-risk）。

## 五、开仓前 60 秒清单（每次必答）
- [ ] 我用的是 Playbook 中哪个编号的模式？（答不出 = 不许开仓）
- [ ] 我的假设一句话是什么？什么情况证明假设错误？
- [ ] 止损位在哪？亏损金额占账户多少 %？（>2% = 减小仓位）
- [ ] 这是计划中的交易，还是盘中冲动？
- [ ] 今天已止损几笔？（≥2 = 不许开仓）
- [ ] 仓位是否符合金字塔规则（首仓 ≤25%，无亏损加仓）？

## 六、交易心理铁则（道格拉斯 + 利弗莫尔）
1. 接受"任何单笔交易的结果都是随机的"，只有长期纪律产生期望值。
2. 不向市场证明自己对——市场不关心你的成本价。
3. 希望 + 恐惧是交易的两大敌人：亏损时满心希望（不砍仓）、盈利时充满恐惧（急兑现）——必须反过来。
4. "赚钱时可以增加交易，亏钱时必须减少交易"（利弗莫尔）。
