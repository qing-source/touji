# 04 风控层：铁律与破产教训（优先级最高，先读这一篇）

## 一、两位大师的破产记录——本 skill 最重要的蒸馏物

### 利弗莫尔
- 一生**四次破产**（1907 前后、1915、1934），最终 1940 年自杀离世。
- 破产原因复盘（他自己承认的）：
  1. 违背自己的规则去"抢帽子"做短线频繁交易（赚快钱诱惑）；
  2. 听信他人消息（棉花案：听信专家 Percy Thomas，违背规则逆势加仓亏损头寸，损失数百万美元）；
  3. 在没有关键点信号时提前进场；
  4. 赚大钱后增加生活开销、心理松懈。
- **结论：他知道所有正确的规则，死于不执行。规则的价值 10% 在写下来，90% 在执行。**

### 索罗斯
- 早期多次濒临出局；1987 年股灾量子基金亏约 26%；1998 年俄罗斯违约重创；2000 年科技泡沫做空过早巨亏。
- 但他从未彻底破产，因为：
  1. "先生存，再赚钱"——每笔结构都先问"错了损失多少"；
  2. 假设被证伪立即退出（1987 年认错一周内砍完）；
  3. 亏钱年份主动收缩基金规模。
- **结论：同样的错误，止损纪律决定生死。**

## 二、账户级铁律（违反任何一条 = 停止交易一周）
1. **单笔风险 ≤ 账户 2%**（按止损价计算，不是按仓位名义值）。
2. **总回撤 10% → 全部仓位减半；15% → 清仓空仓，复盘两周后才恢复。**
3. **同向总敞口 ≤ 75%**（利弗莫尔金字塔上限）；亏损头寸绝不止损位内加仓摊平。
4. **不加杠杆做短线**（融资杠杆会把 2% 风险变成 10%+；两位大师的破产都有杠杆放大）。
5. 连续 3 笔止损 → 强制休息 2 个交易日。
6. 每月提取盈利的一部分锁定，投机账户之外必须有生活储备金（≥12 个月生活费，永不入市）。

## 三、行为级铁律
1. 不听消息、不问别人观点（利弗莫尔棉花案教训）。
2. 亏损头寸过夜前必须重新确认假设，否则砍掉。
3. 不在开盘 15 分钟内和收盘前 10 分钟内做新决策（情绪最乱时段）。
4. 赚大钱后 3 天内不开新仓（防松懈期，利弗莫尔规律）。
5. 永远不和市场争辩：价格是唯一裁判。

## 四、破产先兆自查表（出现 2 项立即降仓 50%）
- [ ] 开始向别人借钱/考虑加杠杆翻本
- [ ] 交易频率明显上升且多数不在 Playbook 内
- [ ] 亏损后出现"下一把扳回来"的想法
- [ ] 不敢打开账户看市值
- [ ] 隐瞒家人交易情况
- [ ] 睡眠受交易影响

## 五、风险声明
短线投机在统计上多数参与者亏损。本 skill 所有规则只能控制单次损失幅度、拉长生存时间，**不能保证盈利**。若无法严格执行 04 篇任何一条，请退出投机，选择指数定投等被动方式。
