# 06 · 资讯部署（News Intelligence）

> 定位：本文件是 skill 的"信息层"——规定看什么、信什么、怎么用。与哲学层（该不该交易）配合：资讯不是开仓理由，是"检验假设的燃料"。

## 1. 信息源分级（决策可信度）

| 级别 | 类型 | 用途 | 例 |
| --- | --- | --- | --- |
| A | 一手权威 | 决策本体 | 交易所/证监会/央行/统计局官网、巨潮公告、部委文件 |
| B | 专业转述 | 取事实弃观点 | 新华社、财新、证券时报、持牌券商研报、Wind/Choice |
| C | 平台聚合 | 情绪/叙事样本 | 同花顺/东财/雪球/微博大V —— 只测散户温度，不作依据 |
| D | 噪音黑名单 | 屏蔽 | 荐股群、带单直播、收费内幕、"稳赚不赔" |

**铁律**：决策只用 A/B；C 级只作为索罗斯反身性的观测样本（当 C 级疯狂而 A 级事实不涨 = 衰竭）；D 级拉黑。

## 2. 四层信息流漏斗（自上而下）

宏观（决定仓位）→ 政策（A股特色驱动）→ 板块（决定目标）→ 个股（决定买卖点）。

- **宏观**：LPR/MLF/社融/M2/PMI/CPI/汇率/外围 —— 流动性总闸门，放水期 P3 概率升。
- **政策**：注册制/退市/减持/印花税/产业文件/降准降息 —— 政策是"维持趋势的工具"，工具耗尽=衰竭前兆（分诊 Q7）。
- **板块**：资金流/催化/龙头表现 —— 利弗莫尔"板块是交易基本单位"（P6）。
- **个股**：公告/量价/风险 —— 先过 60 秒清单，再谈假设与证伪。

## 3. 资讯核验五问

1. 信源级别？（A/B 才可决策）
2. 是否已反映在价格里？（利好不涨=衰竭，索罗斯）
3. 是事实还是观点？（事实可用，观点仅参考）
4. 影响在哪一层？（宏观/政策/板块/个股）
5. 它改变我的计划吗？（不改变就忽略；改变则重跑清单与风控）

## 4. 资讯 × 大师思想对接速查

| 资讯 | 思想 | 行动 |
| --- | --- | --- |
| 利好不涨/龙头滞涨/散户疯狂 | 索罗斯 反馈环断裂 | 减仓、P4 盯防 |
| 政策资金加码、叙事升温 | 索罗斯 正反馈初段 | P3 初段跟进+证伪条件 |
| 产业政策+板块放量共振 | 利弗莫尔 板块最小阻力 | P6 龙头 / P1 突破 |
| 龙头滞涨、补涨乱飞 | 利弗莫尔 趋势末端 | 减仓兑现 |
| 恐慌长阴 | 利弗莫尔 不接飞刀 | 空仓等企稳（Q8→Q9） |
| 谣言/内幕 | 破产教训 | 拉黑 |

## 5. 盘前 SOP（每日 15 分钟）

1. 隔夜扫描（外围/A50/汇率/政策）—— 定大环境；
2. 大师分诊（决策台 9 问）—— 定仓位上限与模式；
3. 板块验证（sector 页热度）—— 定方向；
4. 个股对表（公告/竞价 + Playbook 核对 + 60 秒清单）—— 定买卖；
5. 盘中只看 A/B 级 + 自选异动，C 级情绪留到收盘后记录；
6. 收盘复盘：信息→价格核对，写入交易日志，形成"资讯-交易"闭环。

## 6. 思想一致性声明

本文件不引入任何"内幕/技术指标预测"类主张；全部规则可追溯到公开的方法论：利弗莫尔（趋势/关键点/板块/不接飞刀/破产教训）、索罗斯（反身性/反馈环断裂/工具耗尽）、道格拉斯（流程与纪律）。"资讯分级"与"核验五问"是上述思想在信息层的规则化落地。
